# customer_behavior-_analysis
data analytics project using python, sql and power BI
. Customer Behavior Data Analysis
📌 Overview

This project performs end-to-end data analysis using Python, SQL, and Power BI to extract insights from customer behavior data and support business decisions.

🛠 Tools Used
Python (Pandas, NumPy, Matplotlib, Seaborn)
SQL (PostgreSQL / MySQL / SQL Server)
Power BI
Jupyter Notebook / VS Code
🔄 Workflow
Data loading and cleaning (Python)
Exploratory Data Analysis (EDA)
SQL queries for insights
Dashboard creation in Power BI
Report (PPT) for findings
📊 Key Insights
High-value customers generate most revenue
Sales vary across regions and time
Certain products perform better than others
🚀 How to Run
git clone <repo-link>
cd project-folder
pip install -r requirements.txt
jupyter notebook

📌 Conclusion

The project shows how data can be transformed into actionable insights using a complete analytics workflow.
